# الشهاب للدعاية والإعلان — V5

موقع معرض أعمال عربي، متجاوب، وجاهز للنشر على GitHub Pages.

## آخر التعديلات
- الواجهة الرئيسية أصبحت **اللوجو فقط** في الجهة اليسرى، مع أنيميشن ناعم ولمعة ذهبية خفيفة.
- الهيدر العلوي أصبح يستخدم **رمز S من اللوجو** بدل اللوجو الكامل لتوفير المساحة.
- تم الحفاظ على سرعة فتح/قفل المعرض وسرعة تقليب الصور كما هي في النسخة الخفيفة.
- باقي هيكل المعرض والأقسام وبيانات التواصل كما تم اعتمادها.

## التشغيل
1. فك الضغط بالكامل.
2. افتح `index.html` محليًا للمعاينة.
3. أو ارفع **محتويات** المجلد إلى GitHub Pages.
