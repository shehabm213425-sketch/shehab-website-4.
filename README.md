## تحديث النسخة المنشورة على GitHub Pages
1. افتح https://github.com/shehabm213425-sketch/shehab-website-4
2. فك الضغط عن هذا الأرشيف وافتح مجلد الملفات.
3. استخدم Add file → Upload files، واسحب **محتويات** المجلد، وليس ملف ZIP.
4. عند تطابق أسماء الملفات، سيتم تحديث الملفات القديمة وإضافة الملفات الجديدة داخل مستودع المشروع نفسه.
5. اضغط Commit changes، ثم انتظر اكتمال النشر؛ سيظل الرابط الحالي كما هو.
6. إذا واجهت مشكلة في رفع فولدرات بالمتصفح، استخدم السحب والإفلات من مستكشف الملفات لا نافذة Choose files.
